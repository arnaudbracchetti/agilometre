# Modèle de session : bibliothèque globale, indépendante de l'Équipe

Le Référentiel comptera 60 à 120 Questions à terme (PRD §4) ; composer une Sélection
question par question à chaque Session serait trop coûteux pour le Coach. Le Modèle de
session permet de préparer une Sélection à l'avance et de la réutiliser.

**Décision**: le Modèle de session n'est rattaché à aucune Équipe - c'est une bibliothèque
globale, partagée entre toutes les Équipes qu'un Coach anime. Alternative écartée : un
Modèle par Équipe, plus cohérent avec le reste du modèle (Session et Campagne de pouls sont
toutes deux rattachées à une Équipe), mais qui aurait empêché de réutiliser une même
Sélection type (ex. "diagnostic complet", "check rapide Axe 1") d'une Équipe à l'autre - la
réutilisabilité est la raison d'être du Modèle.
